# Security Policy

## Reporting a Vulnerability

Please report security issues to `1249648969@qq.com`.

For the best response time, please include:
- Description of the vulnerability
- Steps to reproduce
- Affected version(s)
- Any potential patches or mitigations you have identified

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Response Timeline

- **Acknowledgment**: Within 48 hours of report
- **Initial Assessment**: Within 7 days
- **Fix Timeline**: Varies based on severity; critical issues addressed ASAP

## Scope

This security policy covers the BillionMail application and its core components. Third-party integrations and plugins may have separate policies.
